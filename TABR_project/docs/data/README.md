# 实验数据工作簿

`EIE575_TABR_实验数据.xlsx`（Univer 源：`EIE575_TABR_实验数据.univer`）把报告里的结果表整理成可核查的数据表，
并在「图表」页放 10 张原生 Excel 图表。所有图都绑定当前工作簿内的数据区域，改数即改图。

| 表 | 内容 | 来源 |

## 注意

- 「图表」页 A110 起是**图表数据块**：它逐格保存了绘图用的数值，与各数据表同源。改数时两处都要改，或在数据块里改完再核对。
- β扫描是单种子、单事件的补充实验（n=1），不能当统计结论；E0v2扫描属于 v2（目标 CBR 0.60）时代，只用于展示 `grid_exhausted`，不要与 v3.2 的负载阶梯混着用。
- 投递率在源数据里是范围（逐种子不同），表里按文本记录，不参与计算。
