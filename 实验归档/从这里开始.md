## 离线恢复主线工程

在外层解压目录打开 PowerShell，使用 Python 3.11 或更新版本。以下命令调用校准目录中修复 Windows 长路径后的 `restore_e0.py`，会自动找到 11 月 22 日基包和 11 月 23 日差异包。恢复目标须为新目录或空目录。

```powershell
$dest = Join-Path $env:TEMP ('e0_' + [Guid]::NewGuid().ToString('N').Substring(0,8))
python -B -X utf8 ".\2026-11-23_主线E0校准_v2\restore_e0.py" --destination $dest
```

成功后输出 `passed: true`、`accepted_count: 12`、`status: grid_exhausted`。校准目录的 `README_恢复说明.md` 给出独立复算四张 CSV 的命令。11 月 22 日基包含历史模拟器、P2 与 P3 起始检查点、早期 E0 数据及补充研究。11 月 23 日差异包补入最终 E0 原始输入、日志、回执与诊断工具。过渡目录供追溯首轮失败使用；前向运行器更新附有单独的安装和验收记录。
