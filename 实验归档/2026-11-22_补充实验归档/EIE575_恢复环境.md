# 恢复与复算的 Python 环境

查阅 PDF、CSV 和运行清单可直接解压总包。恢复所有组件时，主线 P3 原版恢复程序会重新计算基准数据，需要选用安装了 `jsonschema`、`psutil` 的 Python 解释器。该依赖与原项目的版本说明也在 `components/main_P3_start.zip` 内 `README.md` 中。

此机器的课程分析解释器为 Python 3.13.5，含 jsonschema 4.23.0、psutil 5.9.0。以下 PowerShell 命令从解压后的总包根执行，目标须为新目录。也可在其他机器上使用已有这些依赖的 Python 3.11 或更新版本。

```powershell
$analysis = 'E:\港理课程\.venvs\eie546-lab1\Scripts\python.exe'
& $analysis -B -X utf8 restore_studies.py --study all --destination E:\Temp\e5restore
```

报告使用 Python 3.14.7、ReportLab 5.1.0 和 Windows 等线字体。研究表格复算、读取单次收发记录和报告重建的完整命令在总包 `README_复现.md`。给同一 Python 环境安装上述依赖后，也可以用一个解释器完成全部步骤。
