# EIE575 仿真 MCP 施工手册

## 目标与技术选择
提供启动、状态、日志、停止、结果五个 stdio MCP 工具。复用已安装的 Python 3.14、mcp 1.30.0、psutil 7.2.2，以及原工程 manage.py / analyze.py；不升级仿真引擎、不增加第二个 TraCI 控制端。官方 Python MCP SDK 负责协议，Windows Job Object 管理本任务的整个仿真进程树。无需网页或 HTTP 服务。

## 数据与接口
- `start_run(schemes=["G0"], seeds=[0], request_id=None)`：单次或串行笛卡尔积批次，立即返回 job_id。仅接受 G0–G3、非负整数种子；最多 100 次。同一 request_id 重试返回原任务。当前只支持 S1 两车 30 s 功能场景。
- `get_status(job_id=None)`：指定任务详情；省略则返回环境及最近任务。包括状态、当前方案/种子、仿真时间、完成数、心跳、进程存活与耗时。无进度不直接等同死锁。
- `tail_log(job_id, log="simulation", lines=80, run_index=None)`：限量读取指定任务的日志，不接受任意路径。
- `stop_run(job_id)`：发出取消请求，终止该任务 Job Object 内进程，保留不完整结果，返回取消状态。
- `get_results(job_id, run_index=None)`：默认返回批次精简验收摘要，指定 run_index 返回完整 summary 与文件清单，避免大批次返回过量日志；未完成/被取消、summary.passed 非 true 的运行不判为成功。

持久状态：任务目录下 job.json 原子替换；run_index 从 0 开始；状态为 queued/running/passed/failed/cancelled/interrupted。独立宿主 host.py 接收文件队列并启动 worker，worker 每秒心跳。宿主由普通 PowerShell 的 start_host.ps1 启动，不是 MCP stdio 服务的子进程；这是实测 Windows MCP SDK 会回收整个服务进程树后的设计修正。MCP 断开不应中止宿主及任务。进程身份使用 PID 与创建时间，避免误认 PID 重用。

## 主流程与边界
只读输入 `E:/EIE575_Tools/workspace/EIE575_TABR_Starter`；每个任务在配置的英文工作目录创建副本，仅复制必要源码、配置、脚本及已有 exe，记录 SHA-256。仿真库从原安装读取，不在本阶段改算法。原课程目录与 E:/workspace 在本机实际写入被拒绝，因此本次开发及验证使用获准的 `E:/Temp/eie575-simulation-mcp` 和 `E:/Temp/eie575-sim-runtime`；最终交付完整安装包，正式目录可由安装时指定。

启动前检查宿主心跳、工具/产物存在；文件锁与任务记录保证同时最多一个活动批次。同 request_id 重试先返回已有任务，不受后来环境缺失影响。宿主单例文件锁；新会话不启动重复宿主。每次运行通过现有 manage.run 生成日志并执行 analyze.py。受控子进程在 stdin 收到启动信号前不启动引擎，确保先加入 Windows Job Object；worker 异常死亡时 Job Object 自动清理引擎及后代。无论引擎正常退出还是失败/取消，退出后再发现一次结果目录，保留快速失败的日志入口。停止为中止当前运行和后续队列，不提供单次仿真的保存/恢复。

状态由 worker 持久化，读取接口不写状态。保留原仿真 5 s 日志频率和车辆真值刷新；CBR/收发 CSV 可能缓冲，只作为已落盘数据。批次失败停止，后续标记 skipped。不把现有 S1 功能实验称为正式 S0/S1/S2 实验。

## 模拟与本机验收
1. 单元测试：非法参数/路径、幂等、重复启动互斥、日志截断、进度解析、取消与失败不误判成功。
2. Windows 进程测试：假引擎生成孙进程；停止/worker 退出后全部清理，旁观进程不受影响。
3. 官方 ClientSession + stdio_client 列出恰好五个工具，并调用真实 start/status/log/results；至少完成一个 G0 与 G3 的串行批次，summary 验收通过。
4. 真实运行中调用 stop，确认状态 cancelled、引擎及 SUMO 子进程结束、结果标记不完整。
5. MCP 重连仍可读取原任务；失败输入通过协议返回明确错误。

本机命令使用 `.venvs/courseware-mcp/Scripts/python.exe -B`，具体测试入口写入 README。若注册配置只读，交付配置片段并明确“协议验证通过，当前聊天未加载”；不修改既有 MCP 服务来绕过配置保护。
